# dsh-commit-lint

> DeepSeek Harness 提交消息检查

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## ✨ 功能特性

- ✅ **提交检查**: 检查提交消息格式
- 📋 **暂存区检查**: 检查暂存区文件

## 📦 安装

```bash
npm install dsh-commit-lint
```

## 🛠️ 工具

| 工具名 | 描述 | 参数 |
|--------|------|------|
| `lint_commit` | 检查提交消息 | — |
| `lint_staged` | 检查暂存区 | — |

## 📋 命令

- `/commit-lint` — 提交消息检查

## ⚙️ 配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enabled` | boolean | `true` | 启用插件 |
